Library

Each oligo is clamp + core + reverse complement of the clamp, e.g. GC·core·GC.

Strategy

One reverse-complement-complete master cut into overlapping cores. Segments recombine the master into independent walks and can reach the absolute minimum number of oligos.
Sequence constraints: none
Hard constraints on every oligo. They force the segment strategy.
Replica mode: off
Paste a reference library. Panmer then places every k-mer in a different helical position from the one it occupies there — an independent replica for MD.
